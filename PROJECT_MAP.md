# Карта проекта: Varol Payment Gateway

## Архитектура и суть проекта
**Varol Payment Gateway** — это платежный шлюз (форма для P2P/банковских переводов, прямых ссылок Revolut и криптовалюты), предназначенный для сбора донатов на развитие платформы и инвестиций в проекты с мгновенным оповещением владельца в Telegram.

### 1. Архитектура вкладок интерфейса
На сайте реализована строгая двухсторонняя структура в едином формате:
- **Вкладка Слева: «Донат» (donation)**
  - Назначение: Поддержка платформы, сбор донатов.
  - Порог суммы: от 5 EUR (`min_donation`).
  - Опции: «Поддержка платформы (Донат)», «Анонимный взнос».
  - Методы оплаты: Полный список банковских реквизитов, прямых ссылок и карт из базы данных.
  - Анонимность: Лаконичный тумблер скрытия контактов (по умолчанию включен). При отключении можно указать Telegram/WhatsApp/Email для связи.
  - Результат: Четкая фиксация в БД в формате `Донат: [Название]`.

- **Вкладка Справа: «Проекты» (investment)**
  - Назначение: Инвестиции в действующие проекты экосистемы.
  - Порог суммы: от 250 EUR (`min_investment`) или персональный порог проекта.
  - Список проектов (только реальные инвестиционные проекты):
    1. Маркетплейс Сфера (`SPHERA`)
    2. Словарь нового поколения (`DICT`)
    3. Сингулярный Аксон (`008`)
    4. Опция «Предложить свой проект» (`OWN` — открывает поле ввода названия пользовательского проекта/инвестиции).
  - Методы оплаты: Прямой переход по ссылке Revolut проекта либо банковские реквизиты.
  - Результат: Фиксация в БД в формате `Инвестор: [Название проекта]`.

### 2. Устраненные технические конфликты
- **Устранено пересечение донатов:** Искусственный проект `Донат` (id 10) отключен из списка проектов, так как все донаты теперь централизованно обрабатываются через профильную вкладку «Донат». Исключено задвоение логики и путаница в Telegram-уведомлениях.
- **Устранен дубль «Предложить свой»:** Удален дублирующий проект (id 12), оставлена единая системная опция с кодом `OWN`.

### 3. Backend и Сервисы
- **Веб-сервер:** `app.py` (FastAPI + Uvicorn на порту 8001, проксируется через Nginx на домен `varolpaying.duckdns.org`).
- **База данных:** `db.py`, `database.db` (SQLite).
- **Telegram-бот:** `bot.py` (Aiogram 3, `@varlpay_bot`).
- **Nginx:** `/etc/nginx/sites-available/varolpay` с автопродлением SSL (Let's Encrypt).

### 4. Генерация QR-кода и архитектура переноса домена
- **Нативный генератор QR-кода:** В интерфейс встроена кнопка «QR-код сервиса» с модальным окном (`index.html`, `static/style.css`, `script.js`).
- **Динамическая привязка:** QR-код формируется на лету по текущему `window.location.origin`, позволяя в 1 клик скопировать ссылку или скачать готовый PNG-файл для печати/полиграфии.
- **Сохранение ссылки при переносе сервера:** QR-код кодирует не IP-адрес, а доменное имя. При переносе сайта на целевой сервер заказчика обновляется только A-запись в DNS (IP нового сервера). QR-код, размещенный на любых носителях, не требует перепечатывания и сохраняет полную работоспособность.
